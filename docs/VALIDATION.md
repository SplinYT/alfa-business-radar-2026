# Проверка прототипа

Проверка выполнена 21 октября 2026 года в среде подготовки. Это инженерная проверка, а не результат независимой экспертной оценки качества.

## Автоматические тесты

17 тестов unittest: сквозной HTTP-сценарий входа и сводки, персонализация двух компаний, группа/связи/концентрация, дедупликация и новая новость, отсечение будущих событий, отсутствующая компания, пропуски/NaN, страничная цитата, повторный поиск при пустом результате, allowlist моделей, принятие/отклонение ссылок LLM на mock-ответах и блокировка вызова при исчерпании бюджета, валидация новости/URL, RSS и Atom, запрет XML entities, Origin/CSRF, доступ по компании. Команда: `python -m unittest discover -s tests -v`.

Один ID U_428697 повторяется 12 раз; importer использует последнюю строку. Нельзя заявлять 85 525 уникальных организаций. Вопрос качества источника следует уточнить у организаторов.

Первичный импорт занял около 13,6 с; сводка для компании с максимальной выручкой — около 0,25 с без LLM, 5 карточек. Это единичный прогон на конкретной среде; не нагрузочный benchmark и не SLA. Результаты зависят от оборудования.

Визуально сверена первая страница обзора ставки с её OCR. Полная ручная вычитка 64 страниц не выполнялась. Повреждённое при рендере PNG страницы 18 FI_Strategy повторно отрендерено; пустых OCR-страниц в итоговом JSON нет. Непустой OCR не гарантирует точность таблиц или чисел.

## Что ещё не подтверждено

- Docker build/run: Docker daemon отсутствует в среде подготовки. Python server и HTTP API проверены напрямую.
- Генерация разрешённой LLM: нет endpoint/ID/ключа организаторов. Не заявляется успешный реальный inference или соответствие финансовому лимиту общего ключа.
- Живой RSS: парсеры проверены на RSS/Atom fixtures; доступность выбранной реальной ленты и её лицензию нужно проверить при настройке.
- Production-SSO, многопользовательская tenant-изоляция, PostgreSQL/очереди/кэш не реализованы.
- UI реализован, но полный браузерный прогон в среде подготовки не выполнен: облачный браузер не имеет прямого доступа к локальному HTTP server. API end-to-end не заменяет визуальную QA.
- Релевантность и причинные выводы не измерены на разметке экспертов. Предлагаемая следующая проверка: 30–50 новых событий × 3 профиля × 3 роли; независимая оценка полезности и обоснованности, nDCG@5 и доля неподтверждённых утверждений. Числа метрик в решении не выдуманы.

## Условия приемки перед сдачей

Запуск Compose с нуля; два разных клиента; новая новость без правки кода; реальная разрешённая LLM с проверенными ссылками; сопоставление OCR с оригиналом; доступ жюри к удалённому репозиторию; точный SHA версии и дата сдачи из платформы. См. SUBMISSION.md.
