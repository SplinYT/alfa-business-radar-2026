# Что исключено из Git

.env и API-ключи; исходные CSV; полный OCR аналитических материалов; исходные PDF; runtime SQLite и журналы. Эти файлы не были опубликованы. В архиве для участника CSV и OCR доступны в data/private и игнорируются Git. Никаких паролей/ключей шлюза в комплекте нет. Пароль demo-radar-2026 является публичной тестовой конфигурацией и должен быть изменён для внешнего сервера.

В модель передаются минимальные отраслевые/продуктовые признаки, событие и выбранные фрагменты аналитики. Полные графы платежей, идентификаторы компаний и физлиц не отправляются как профиль. Сам текст новости может содержать ID/данные, введённые оператором; автоматическая DLP-фильтрация произвольного текста не реализована.
